# Fellow Servants - GitHub Pages package (Version 8.48)

Keep `index.html` and the `images` folder together.

## Upload/update
1. Unzip this package.
2. Open the `site` folder.
3. Upload `index.html`, `README.md`, `manifest.json`, and the complete `images` folder to the root of the GitHub repository.
4. Replace files with matching names.
5. Commit the changes to the `main` branch.
6. GitHub Pages will republish at the same website address.

Upload the contents of `site`, not the ZIP itself.
