# Fellow Servants - GitHub Pages package (Version 8.47)

Keep `index.html` and the `images` folder together.

## Upload/update
1. Unzip this package.
2. Open the `site` folder.
3. In the GitHub repository, replace the existing `index.html` and `images` folder with these versions.
4. Commit the changes to the `main` branch.
5. GitHub Pages will publish from the main branch and root folder.

Do not upload the ZIP itself as the website. Upload the contents of the `site` folder.
