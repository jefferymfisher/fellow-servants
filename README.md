# Fellow Servants - GitHub Pages package

Keep `index.html` and the `images` folder together.

## Upload
1. Create or open a GitHub repository.
2. Select **Add file** > **Upload files**.
3. Drag `index.html` and the entire `images` folder into the upload area.
4. Commit the upload.
5. In repository **Settings** > **Pages**, publish from the main branch and root folder.

Do not upload the ZIP itself to the website repository. Unzip it first, then upload the contents.
